# Vantier OS: Claude-native stack (replaces Base44)

- `CLAUDE.md`: the business brain (offer, voice, brand, where everything lives, safety rules).
- `skills/`: Claude Skills (Meta ads operator, lead finder, outreach writer, campaign strategist). Upload each folder as a skill in claude.ai → Settings → Capabilities → Skills.
- `routines/`: the scheduled automations and the Base44 cutover runbook.
- `website/`: invantier.com source (Vite + React + Tailwind). `npm ci && npm run build`. Live preview: https://soto81588.github.io/cllauxd/

Lead, client and outreach data is private: it lives only in the Vantier OS artifact database, never in this public repo.
